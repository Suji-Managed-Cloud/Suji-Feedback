## What is Suji?

Suji provisions a dedicated Linux VM for you in EU data centers in about a minute. Install apps from the marketplace in one click — [OpenClaw](https://github.com/openclaw/openclaw), n8n, Ghost, NocoDB, Plausible, Wiki.js, and more — and run everything from one dashboard.

### Features

- **Dedicated VMs** — every instance is an isolated virtual machine you own, not a shared container
- **One-click marketplace** — install, upgrade, and uninstall apps from the catalog ([suji-hq/suji-templates](https://github.com/suji-hq/suji-templates))
- **Full ops from the dashboard** — web terminal, file browser, live logs, metrics, firewall
- **Public HTTPS out of the box** — each exposed app gets its own `*.suji.fr` subdomain
- **Snapshots & spending caps** — back up your VM and keep the bill predictable

## How to use this repo

### Report a bug

Have an idea? [Submit a feature request](https://github.com/suji-hq/Suji-Feedback/issues/new?template=feature_request.md).

### Browse existing issues

Check [open issues](https://github.com/suji-hq/Suji-Feedback/issues) to see what's already been reported or upvote existing requests with a :+1: reaction.
